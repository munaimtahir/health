# Security Policy

Status: Active.

Report suspected vulnerabilities privately to the repository maintainers; do not publish health data, credentials, exploit details, or patient examples in an issue. Include a reproducible technical description using synthetic data.

The project forbids secrets, real patient data, analytics/advertising SDKs, sensitive logs, public document storage, and custom cryptography. Dependencies, Keystore boundaries, app lock, backups, deletion, migrations, file validation, and export/share flows require security review.
