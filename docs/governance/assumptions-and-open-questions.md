# Assumptions and Open Questions

Status: Draft. Purpose: identify items requiring confirmation before production features.

- Exact stable versions will follow the installed Gradle/Android toolchain and the version catalog.
- Encryption format and key rotation require a dedicated security review before sensitive storage ships.
- Product legal review is required for the final privacy policy, health-app declaration, and supported jurisdictions.
- The scaffold uses no runtime permissions; notification, camera, and file-access permissions remain feature-specific.
- Target device coverage and API 26 emulator availability must be confirmed during release hardening.
