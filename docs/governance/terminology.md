# Terminology

Status: Canonical. Purpose: keep product and code language consistent.

| Term | Definition |
|---|---|
| Health record | Any user-owned structured or attached personal health information. |
| Medical document | An imported or captured original file such as a report or prescription. |
| Health event | A dated item shown on the unified timeline and linked to source data. |
| Symptom entry | A user-recorded observation of a symptom at a time; it is not a diagnosis. |
| Reminder | A user-created notification for a planned follow-up or task. |
| Follow-up | A clinician- or user-originated plan recorded by the user; never app-prescribed. |
| Appointment summary | A user-controlled, concise report assembled from selected records. |
| Active medication | A medication regimen currently marked active by the user. |
| Previous medication | A historical regimen that is no longer active. |
| Personal health profile | The single person’s demographics, allergies, conditions, and history. |
| Health timeline | A chronological projection of linked health events. |
