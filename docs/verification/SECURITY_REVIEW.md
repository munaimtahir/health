# Security review

Implemented: local-only boundary, salted PBKDF2-HMAC-SHA256 PIN verification, Keystore AES/GCM PIN-material wrapping, lifecycle lock gate, persisted 5/15/30-minute inactivity timeout options, private UUID-named document storage with SHA-256, FileProvider sharing path, privacy-safe notifications, encrypted backup authentication, tamper rejection, and restore cleanup. The connected device now has an instrumentation check for biometric capability handling; its hardware is present but no biometric enrollment is available, so a successful biometric unlock is not claimed. The timeout setting is enforced by the Compose lifecycle gate and resets on backgrounding; it does not expose health data while locked. Remaining hardening is the final security/performance acceptance sweep and release artifact reinspection.
