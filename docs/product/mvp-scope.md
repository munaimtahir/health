# MVP Scope

Status: Canonical. Purpose: distinguish required MVP capability from scaffold placeholders.

MVP includes a single-user profile; medical information, allergies, diagnoses, procedures; timeline; symptom logging; medical-record vault; medication history; follow-up planner; appointment preparation and PDF summary; local backup/restore; export; app lock; and offline-first operation. The current scaffold implements only the navigable shell and foundations. Feature behavior is scheduled by [`../delivery/development-sprints.md`](../delivery/development-sprints.md).
